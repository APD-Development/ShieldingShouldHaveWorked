## Evidence and production change

Its delayed `swap` callback used only backpack membership and the non-Bag condition, so a stale selection that no longer exposed DROP could still be detached. `FullPackSwap.canSwapOut(hero, pack, chosen)` now implements the original picker rule in one place and is called both by `itemSelectable` and immediately before any swap-time journal note, detach or time consumption.

Three new headless tests cover a formerly droppable item losing the action while selected, inventory membership being removed, null inputs, and a real PotionBandolier in the pack being rejected. Existing drop and pickup costs, heap checks, item types, save data, RNG, scoring v6, original signing/app ID/version code, C466R7 items/sprites/FullPackSwap/ThrowAim/Metamorphosis/search/playback and C485+ history remain unchanged.
