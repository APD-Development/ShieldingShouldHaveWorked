## Newly identified independent source bug
Production `ArchiveImporter.importZip` already validates archive entry names to `runs/<plainID>.apdlog` and `legacy/<plainID>.apdlog`, but its `commit` method formed a File from `root` and that safe *textual* path without checking whether a pre-existing destination folder or file is a symbolic link. A malicious/stale `runs/` directory symlink could redirect a newly accepted log **outside the designated history folder**. A pre-existing log symlink to external bytes could be hashed/read as `skippedAlreadyHere`, silently treating an external file as device-owned history. These are narrow filesystem integrity bugs, not a claim any owner's history was corrupted.
