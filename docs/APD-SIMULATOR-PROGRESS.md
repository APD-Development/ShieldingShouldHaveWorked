# APD Simulator Progress

Checkpoint: `research/apd-simulator`, 2026-10-14

## Implemented

- Added a test-only headless gameplay harness that initializes a seeded real APD run, generates levels 1 through 5, performs legal local movement and a food pickup, fights a rat, and reaches the generated Sewer Boss level.
- Added a deterministic combat policy for the real Goo encounter. It uses real hero attacks, Goo turns, movement, healing potions, upgrades, and the healing buff; the seeded transcript records per-turn HP, damage, actions, and resource count.
- Added a replay regression that runs seed `638194` twice, compares the transcripts, and requires the hero to survive and defeat Goo.
- Added headless guards around graphical callbacks/effects used by the test path in hero drops, Goo, potion effects, grass drops, and `GameScene`.

## Current Capability

The only verified playable policy is a fixed-seed Warrior scenario. It exercises real engine combat and Goo mechanics in headless mode and produces a reproducible test transcript. The fixture explicitly selects Warrior; the Mage unlock message is a side effect of using a scroll and is not Mage gameplay coverage.

## Unfinished / Not Verified

- No verified Mage result is present in this checkpoint, and Rogue, Huntress, Duelist, and Cleric are not simulated. There is no class-specific policy selection or regression matrix.
- Levels 1 through 5 are generated by directly entering each level in test support. The harness does not yet navigate doors, stairs, keys, quests, or ordinary floors as a complete legal run.
- The strategy adds test resources directly and is not yet a general agent that observes state and chooses from the full legal action set.
- Tengu and all other bosses are unimplemented in the gameplay harness.
- Difficulty settings, challenges, robust multi-seed evaluation, failure classification, and a public simulator API are not implemented.
- The harness does not verify recorder-backed end-to-end run statistics; its per-turn transcript is test-local.

## Next Milestones

1. Keep the Warrior Goo victory deterministic while extracting reusable legal-action and state-observation interfaces from the test driver.
2. Add reproducible Goo scenarios for each of the six classes, retaining any previously verified Mage and Warrior seeds as fixed regressions.
3. Implement Tengu mechanics and a legal, class-aware policy; add deterministic tests for all six classes and replay.
4. Replace direct level entry and resource injection with legal exploration, progression, and resource acquisition; prove runs across floors 1 through 5.
5. Expand to further bosses, then cover difficulty/challenge combinations, multi-seed reliability, and complete-run statistics.
