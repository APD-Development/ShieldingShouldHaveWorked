APD records history, format 2
One block per milestone, newest first. Not shown in the game yet: the Statistics/Records screen will display this
later. Each block is a header line with four fields separated by vertical bars (milestone id, telemetry version or a dash,
APD version, date) followed by "- " lines. Never edit or reuse an old milestone id, add a new block at the top.

The telemetry version is the version of APD's recording system (Telemetry 1.0, 1.1, 2.0, ...). It is separate from the
APD game version, and every recorded run keeps the telemetry version that recorded it. "-" means the milestone is not
tied to a version of the recorded data. Minor versions only add things, a new major version changes what existing
data means.

telemetry-1.0-storage | telemetry 1.0 | APD 4.0.8-apd | 2026-10-06
- Telemetry 1.0 defines how a run is stored: one append-only log per run whose header names the telemetry version, made
  of individually checksummed, length-prefixed frames, with a per-log string table and a seal frame at the end of a
  completed run.
- Logs that were cut off or damaged at the end recover to their last valid frame, and the damaged bytes are kept.
- A small run index lists the logs. It can always be rebuilt from the logs, which are the evidence.
- Telemetry 1.0 records no game events yet. Runs are recorded from a later build, and the events they contain are added
  in later 1.x versions.

phase0-baseline | - | APD 4.0.8-apd | 2026-10-06
- Test harness and golden seeded-level baseline added before any recorder code, so later builds can prove that
  recording does not change how dungeons are generated.

why-apd-keeps-history | - | APD 4.0.8-apd | 2026-10-06
- Shattered Pixel Dungeon only keeps a top-11 list of runs, a total and win count, lifetime item-use and enemy-kill
  totals, and which badges are unlocked. Every other run, and all detail about how a run went, is lost when it ends.
- APD is being built to keep the raw history of every run so that statistics can be calculated from it, including
  statistics nobody has thought of yet.
- Runs that were played before APD recorded history can only ever contain what SPD kept, so they hold less
  information than runs recorded by APD itself. Missing information stays missing, it is never guessed.
